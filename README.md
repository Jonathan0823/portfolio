# Eguin portfolio

Astro site for eguinjonathan.com. See GLOSSARY.md for domain terms and docs/ for agent and ADR notes.

```
pnpm install --frozen-lockfile
pnpm dev      # local dev server
pnpm test     # unit tests
pnpm check    # astro check
pnpm build    # static build into dist/
pnpm lhci     # Lighthouse CI on / and /story, mobile and desktop (min 95; set CHROME_PATH if needed)
```
