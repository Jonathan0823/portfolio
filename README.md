# Eguin portfolio: mockup export

Plain HTML exported from the design canvas. Open `index.html` in a browser.

- `index.html`: desktop Home (fixed 1440px layout). Phones are sent to `mobile.html`; add `?desktop` to force desktop.
- `mobile.html`: phone layout (390px).
- `story.html`: the long story page.

Everything is inline: the pixel engine (header field, cursor, trail, glyph spill, GitHub calendar, experience squares, navbar) is the `Component` class in the script at the bottom of each file. Fonts load from Google Fonts (Geist, Geist Mono).

This is a mockup, not production code: the layouts are fixed-width, the content still has [placeholders], and the GitHub calendar uses sample data.
